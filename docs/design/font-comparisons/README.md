# Okyo Onboarding Font Comparisons

10-font side-by-side comparison for the ScanPage showcase screen ("Scan any dish. Get the recipe.")

## Files

- **font-comparison-template.html** — Full comparison page with all 10 fonts rendered simultaneously in iPhone mockups

## Fonts Compared

1. **Sora** — Current selection; rounded, friendly, modern
2. **Inter** — Classic geometric sans; highly legible, neutral
3. **DM Sans** — Display-focused; slightly geometric, approachable
4. **Manrope** — Rounded sans; similar warmth to Sora, slightly different letterforms
5. **Plus Jakarta Sans** — Modern geometric; tech-forward, clean
6. **Outfit** — Transitional sans; balanced, contemporary
7. **Urbanist** — Very rounded; playful, softer than Sora
8. **Lexend** — High legibility focus; distinctive letter spacing
9. **Nunito Sans** — Friendly rounded sans; warm but busier than Sora
10. **Space Grotesk** — Monospace-inspired; tech, sharp

## How to Use

1. Open `font-comparison-template.html` in a desktop browser (Chrome, Safari, Firefox recommended)
2. All 10 fonts render simultaneously in iPhone 12 Pro mockups with identical content
3. Each mockup shows:
   - Title: "Scan any dish. Get the recipe."
   - Body: "Take a photo and Okyo identifies the ingredients, then gives you a recipe you can make at home."
   - UI elements (back button, progress dots, Next button)
4. Font labels below each mockup for easy reference
5. Scroll to view all fonts; responsive grid adapts to screen size

## Design Notes

- All fonts use Google Fonts for reliable rendering
- Weight mapping: Headlines 700, Body 500, Button 600
- Exact sizing and spacing matches production ScanPage layout
- Font sizes: Headline 32px, Body 14px, Button 17px
- Line heights: Headline 38px, Body 20px
